# 棋牌扩展与规则调研

## v0.3 实现

棋类仍为默认大厅，牌类有独立图赏、规则页和牌桌。先落地三人经典斗地主和三人 48 张跑得快，两者共用扑克牌、牌型识别、回合事件、交接屏、语音、设备档案及复盘机制。

| 玩法 | 手牌和身份 | 本版设置和规则 |
| --- | --- | --- |
| 经典斗地主 | 一副 54 张，17 张每人，底牌 3 张。轮流叫 0–3 分，较高叫分者成为地主，全不叫则重发 | 一人对两电脑或三人同屏接力。地主先出，农民合作。按同型同张数比大小，支持飞机、四带牌、炸弹、王炸。炸弹与王炸计翻倍，本局计分存档 |
| 跑得快 48 张 | 去大小王、红桃/方片/梅花 2 与黑桃 A，每人 16 张。持黑桃 3 者首出且首手须带黑桃 3 | 一人对两电脑或三人同屏接力。有牌必管可选。支持单张、对子、连续对子、三张及其带牌、飞机、四张炸弹。以首个清空手牌定胜，按剩牌做休闲计分 |

两套规则均采用可在游戏内查看的固定规则版本。跑得快民间另有 15 张、报单和四带牌等细则，分别建规则预设，不能把不同地方条款隐式拼到同一局。斗地主叫分结构参考经典玩法公开说明，暂不包含抢地主、明牌、春天或癞子倍数。 [经典斗地主玩法](https://www.tuantuangame.com/doudizhu/gameRule.html) · [JJ 跑得快规则](https://www.jj.cn/news/320/20111115101400019865.shtml)

## 存档、联机与验收

- 当前牌桌可从开局种子和动作流重建，依牌手档案保存。开局配置存入记录。接力模式在每次换人时清空当前手牌显示，同意接手后才露出该座手牌。
- 联网服务器持有完整牌序，生成公开桌面与每座私有视图。重连按座和序号恢复。牌桌不能直接复用公开棋盘的完整局面广播。先验证好友房与隐藏手牌，再做正式匹配、分层段位和旁观。
- 每种玩法验收洗牌唯一性、先手、无效动作、跟牌数量、过牌恢复、结算、回放稳定性和界面手牌隐私。长期用公开规则例局、随机可完成性和移动视口操作测试限制回归。

## v0.4 锄大地

采用独立的四人家庭规则。52 张牌，无大小王，四人各 13 张。方块 3 持有者先出且首手须带方块 3。三家连续过牌后收牌，由上一手出牌者重新领出。

花色从小到大依次方块、梅花、红桃、黑桃。三种基本牌型同张数比较，五张牌按顺子、同花、葫芦、四条带一、同花顺升序。顺子允许 3 至 A，四条与同花顺仅参与五张牌比较。残局按各自余牌计分。支持四人同屏换手、单人对三台电脑、牌型语音、同花顺演出和牌局复盘。 [四人锄大地玩法资料](https://www.playfacetoface.com/zh-hans/how-to-play-big-two/)

## v0.5 手牌、报音与复盘

- 跑得快加入 45 张牌组选项。移除大小王、非黑桃 2、非黑桃 A 和方块 K，每人发 15 张。黑桃 3 首出，必管可选，牌型和剩牌计分沿用应用内规则。保留原 48 张牌组和旧棋谱。十五张玩法的牌组参考联众示例，首出及末手规则以开局页内说明为准。 [联众十五张跑得快](https://www.gameabc.com/news/2019-12-10/6249.html)
- 三种牌桌均可选入门、标准与挑战。难度主要影响电脑出牌组合的启发式排序。叫分、过牌、重领、飞机带牌、点数、剩牌与结算均可触发普通话报音。
- 新增墨蓝牌面、清空已选手牌、长组合展开动画及强牌声光反馈。牌谱和棋谱共用倍速播放、首尾跳转和进度拖动。

## v0.3 功能审查

| 检查项 | 本轮结果 |
| --- | --- |
| 报音与音量 | 原版只有合成声。本版使用本地 WAV，首次交互解锁音频，报音、撞击与音乐可分别调整。浏览器验证样本实际解码并开始播放，炮打动作验收使用实走触发 |
| 对局设置 | 打开设置时暂停棋类和牌类人机回合。牌桌的选牌提示与出牌动画读取公共设置。牌局回放不触发声音、不显示手牌 |
| 接力隐私 | 每个动作和刷新后重新隐藏手牌，接手确认后只显示当前座位。存档只在设备内。联网版本仍需服务端公开和私有视图 |
| 本地存档 | 继续兼容旧棋谱与偏好，牌局结束后归档。对局导出包含棋谱与牌谱，旧棋类入口与回放继续通过回归 |
| 音画与打包 | 分别检查桌面和手机视口的图赏、字体、交接和出牌。调试 APK 核对签名及本地音频资产。Android 真机听感与帧率还需实测 |
