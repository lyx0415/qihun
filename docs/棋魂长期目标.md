# 棋魂长期目标

以中国象棋为主厅，把棋、牌和桌游做成一个可离线练习、可与朋友开桌、可保存和研究对局的棋牌馆。大厅由棋类与牌类两个主要入口组成。长期以 **30 个经过验收的规则包**为目标，覆盖 2–6 人桌型。每个规则包都交付完整的一局、电脑或同屏模式、独立规则页、可重建的棋谱或牌谱，以及面向小屏的棋具或牌面。

| 阶段 | 交付内容 | 进入下一阶段的验收条件 |
| --- | --- | --- |
| 0.5 本地体验 | 九种棋与三种牌。象棋让子、围棋大棋盘及人工确认数子、恰五、十五张跑得快。共用语音设置和复盘播放器 | 旧档续局，新设定可重放，棋类与牌类的普通动作、关键动作和结算均有声音和视觉反馈 |
| 本地训练与规则扩容 | 象棋番棋和残局题库、练习难度与错题复练、围棋和国际象棋棋谱导入、更多跳棋和飞行棋开局。跑得快地区细则、掼蛋、升级和地方麻将分批加入 | 每个规则包固定版本、公开采用的规则和偏差，有最小对局、边界例局和种子回放。地方规则能在开局前查看 |
| 好友开桌 | 手机账号、好友房、邀请码、预约约局、断线续局、同桌表情与消息、同意制悔棋、让子、双人计时、受控旁观 | 服务端复核每步着法。牌桌只向本人发送其手牌。断线、重复发送、冲突、时钟与重放均通过双端测试 |
| 全国棋友与长期成长 | 跨地区匹配、定级和分玩法段位、俱乐部、周赛、比赛棋谱、练习报告、跨设备同步，逐批增加 2–6 人休闲桌游 | 可分玩法观察掉线率、结算一致性、匹配等待和社区处理时效。Android 与微信渠道逐一通过真机验收和发行审核 |

## 体验验收线

- 音效按事件设计，包含普通动作、特殊着法、吃子或压牌、轮转、胜负与分差。语音、效果与配乐可独立调音量，完整与关键报音可切换。语音素材逐步引入可授权的真人演绎与可选语音包。
- 以 360–430 CSS 像素宽手机做常用棋局的必测范围。目标是在选定的中低档 Android 机型上，常用着法和出牌的触摸至画面反馈 p95 不超过 50 ms，移动、翻子和大型出牌动画目标为 60 fps。完成指标需要实机连续对局和性能采样。
- 大棋盘、长棋谱、人机和多方接力分别测量。每次规则升级检查旧存档可读、完整重放和设备恢复，确保断网时仍能玩本地游戏和查阅本地记录。
- 公共账号区分本地档案和云记录，规则状态与账号数据通过稳定版本标识关联。棋谱可由用户导出，后续同步前需验证备份恢复、冲突和多端合并。
- 微信先完成规则引擎、绘制、本地存储和音频的独立验证，再试做适配层。Android 先从现有离线应用与真机验收继续，正式发布时使用发行签名。
